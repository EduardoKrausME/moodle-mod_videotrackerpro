# Video Tracker Pro

Video Tracker Pro is a Moodle activity for detailed, provider-independent playback analytics per learner and per playback session. It does not implement a video player, provider adapters, basic tracking or its own viewing map; those responsibilities belong to `local_video_bridge`.

The activity answers operational questions about playback evidence: how many sessions were needed, active playback time, watched coverage, pauses, seeks, repeated or skipped ranges, playback rates, the last observed point, and whether a session reached the end. A session that finishes before `ended` is shown as a session that ended before the video finished; that is descriptive evidence and must not be interpreted as disinterest.

## Sessions

A playback session is identified by a UUID generated by Video Bridge and persisted as one compact session record. High-frequency events are aggregated in the browser; raw `timeupdate` events are never written one row per tick. Detailed telemetry stores compact watched ranges and positional evidence, while server timestamps and bounds are used to limit trust in browser-supplied values.

Video Tracker Pro requires `local_video_bridge >= 2026100616`, asks the bridge for `DETAILED` telemetry and reads facts through the public analytics/progress APIs. The module itself stores only activity configuration.

Each session exposes server-anchored start/end timestamps, real session duration, active playback time, paused time, start/end positions, authoritative watched percentage at session start/end, seeks, pauses, playback-rate changes, the normalized ordered event timeline, whether the player emitted `ended`, and a descriptive end reason.

## Metrics

Teacher reports expose watched percentage, total active playback time, session count, pause count, seek count, weighted average playback rate, last saved position, last view and completion. Per-user drill-down exposes the session list and compact timeline evidence, including pause points, forward/backward seeks, playback-rate distribution and the final point of the session.

The viewing map and authoritative watched percentage always come from `local_video_bridge\progress\manager`. The browser never decides completion.

## Provider limitations

Only Video Bridge providers declaring capability `tracking` can be selected. The quality and granularity of analytics depend on what the provider adapter can observe reliably. The module never contains YouTube, Vimeo, Bunny, Panda, Qencode, OTTFlix or other provider-specific code.

## Interpreting analytics

These metrics describe observable player behavior, not learner intent. A pause can mean note-taking, interruption or technical delay; a seek can mean review or navigation; a session that ends before `ended` is not evidence of disengagement by itself. Reports should be read as playback evidence, not as a psychological conclusion.

## Privacy

Playback progress and detailed session telemetry are stored by Video Bridge under the module context and consumer identity `mod_videotrackerpro`. The Moodle Privacy API exports and deletes those records for the activity. Activity deletion also removes bridge-owned progress and session telemetry through the bridge consumer API.
